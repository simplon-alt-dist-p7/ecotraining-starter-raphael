# Cartographie du projet

## Description du projet

Application vitrine où sont listés des éléments appartenant à des catégories. Dans le cadre de mon projet, un bestiaire pour du Jeu de Rôle, où chaque créature dispose d'une image.

## Objectifs visés

1- Optimisation des médias, plus spécifiquement des images affichés et de leur poid.
2- Structurer le style CSS du frontend
3- Délimiter les fonctions qui se répètent
4- Réduction du code inutile et des extensions inutilisées
